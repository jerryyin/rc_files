# Gist

Linux setup installs `gist-paste`. Explicit credential setup writes its local `~/.gist` token from the vault's `gh_token_jerryyin.txt`. `GIST_KEY_FILE` or `GH_JERRYYIN_KEY_FILE` selects another token; `GIST_CONFIG` selects the destination. Normal setup does not read the vault. This package makes no Windows installation or login changes.
